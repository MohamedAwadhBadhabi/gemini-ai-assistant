# Gemini AI Assistant

A Python-based AI assistant that integrates with Google's Gemini API to generate AI-powered responses. This project demonstrates API integration, environment variable management, error handling, retry mechanisms, and basic automated testing.

## Project Overview

The application accepts a user prompt through the command line, sends it to the Gemini API, and displays the generated response.

The project is structured to separate application logic from API request handling, making the code easier to maintain and test.

## Features

- Google Gemini API integration using the official `google-genai` SDK.
- Secure API key management using environment variables.
- Command-line prompt input and validation.
- Centralized API request handling.
- Error handling for common API failures.
- Automatic retry mechanism for temporary API errors.
- Basic automated tests using Python's `unittest.mock`.

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd 02-Gemini-AI-Assistant
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

Windows:

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure the API key

Create a `.env` file in the project root directory:

```env
GEMINI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your own Gemini API key.

**Security:** Never commit or share your `.env` file or API key.

## How to Run

Run the application from the project root:

```bash
python main.py
```

Enter your prompt when requested, and the application will display the response generated by Gemini.

## Error Handling and Retry Logic

The application handles common API errors, including authentication failures, invalid requests, permission errors, missing resources, and rate limits.

A retry mechanism is implemented for selected temporary API errors.

The retry mechanism uses exponential backoff, increasing the waiting time between consecutive attempts, with a maximum of three attempts by default.

Non-retryable API errors are raised immediately instead of being retried.

## Testing

The project includes tests for:

- Successful retry after a temporary API failure.
- Handling maximum retry attempts.
- Handling non-retryable API errors without unnecessary retries.

The tests use mocked API responses, so they do not require real Gemini API calls.

## Security Considerations

- API keys are loaded from environment variables.
- `.env` is excluded through `.gitignore`.
- Virtual environments and Python cache files are excluded from version control.
